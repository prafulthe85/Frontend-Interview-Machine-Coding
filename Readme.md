# React Frontend Machine Coding Question

## 1. Pagination Implementation at Frontend

### Objective
- Implement client-side pagination in a React application.
- Display large datasets in smaller, manageable chunks.
- Improve performance and user experience.

### Functional Requirements
- Fetch and display data from an API or static dataset.
- Show a fixed number of records per page (e.g., 10, 20, 50).
- Implement navigation controls:
  - Previous button
  - Next button
  - Page number buttons
- Highlight the currently active page.
- Disable navigation buttons when:
  - On the first page → Disable **Previous**
  - On the last page → Disable **Next**
